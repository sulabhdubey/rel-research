# Rights, dependencies and public-release scope

This public technical-review package is published by Sulabh Dubey for reading, discussion and inspection. This release does not select a separate open-source or broad redistribution license. Public availability is not an assertion that every included work is public domain. GitHub's platform terms govern its view/fork facilities; further reuse rights are not expanded by this note. Third-party rights remain with their owners.

The REL instructions, derived study summaries, arithmetic verifiers and localization reference were produced in this research programme with model assistance. The historical diagnostic contains study-generated code and a labelled repair. Third-party papers, raw datasets and external dependency code are not bundled. Linked sources retain their respective terms; citation does not grant rights to their content.

Runtime dependencies: Python standard library for the arithmetic verifiers; NumPy 2.4.6 for the constructed reference/test suite. Tested environment: Python 3.13.7 on Windows. These are external dependencies, not vendored; no installation happens automatically. ReportLab, pypdf and pypdfium2 were used locally to produce and inspect PDFs, and are not needed by readers to run the checks.

The current 21-file generic skill snapshot is reader context, not a reconstruction of historical treatments. Full original prompts, native hosts, model transcripts, raw source arrays and private observational receipts are absent. Historical private-source links are provenance pointers and may be inaccessible; they are not needed for the supplied standalone entrypoints. No complete historical replication, peer review or security certification is implied.

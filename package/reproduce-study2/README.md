# Offline table reproduction

Run `python reproduce.py` with a standard Python 3 installation. No network,
model, external package, credential, Docker engine or GPU is required. It checks
the bundled manifest, matched-block inventory, token arithmetic and exact
reported aggregates. Reasoning tokens are already inside output tokens.

The CSV contains all 24 completed native adaptations and their corresponding
unchanged E3 executions. Historical acquisition is separate. Every arm may reuse
its own E2 output at E3; A lacks only prior-origin history at E2. Token totals
include failed tool operations and repairs inside native attempts. They exclude
unmeasured parent/reviewer work, physical energy and monetary cost. Replays have
zero new model requests but nonzero execution costs.

This export reproduces accounting from saved records. It does not authenticate
the original event logs, rerun the model experiment, prove causal attribution,
or establish broad RSI effectiveness. Raw trajectories remain in the local
evidence archive; they are not silently included in this shareable package.
Source cases come from the public JSON Schema Test Suite at commit
55719286c33ae0d1823bfb65fea10338a19bc37c. The paper states scope and prior art.

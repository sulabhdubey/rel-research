# Public export v0.7.1

Published from the reviewed v0.7 package, 5 November 2026. This is a packaging/privacy revision, not a new experiment or peer-reviewed edition.

Changes: remove the component map's local workspace metadata; correct private-delivery wording in the paper, appendix, brief and rights/readme files; add public export identity; omit social-message drafts; regenerate matching PDFs and the complete byte manifest. The current REL snapshot, numerical observations, saved accounting, method implementations and tests are unchanged.

Earlier review notes are historical receipts scoped to their original bytes. The public export received a separate prepublication review. In particular, an earlier raw-text privacy check missed a JSON-escaped local path; this export removes it and adds decoded-structured-field inspection. Scanner success does not prove absence of every possible secret or certify security.

Public readers can inspect and reconstruct the selected tables using included scripts and inputs. They cannot reauthenticate the original provider events, rerun the original native-model trials or reproduce raw-sensor scoring from this package alone. No raw chats, account identifiers, credentials, private project files or third-party paper/dataset copies are intentionally supplied. The credited author name and public GitHub identity are intentional.

Historical pinned links to the private research repository remain labelled provenance pointers. They do not grant access and are not prerequisites for the standalone checks. The original private archive and Git history have not been made public.

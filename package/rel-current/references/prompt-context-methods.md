# Select context, method and output

Experimental optional reference; benefit has not been established. Use it when an observable information gap, changed requirement or unresolved method choice could change the next action. If the current instructions and evidence suffice, execute directly. Do not turn selection into another form, model call or catalogue review.

## Preserve the requested result

Recover the current goal, required artifacts, audience, acceptance conditions and authority from the existing request or task brief. Separate requirements from assumptions. Compare a retained method's input, behavior and output contract with the current one before reuse. Similar names or prior success do not establish compatibility. Reuse, adapt or reject the method according to that comparison; do not change the task to fit it.

## Choose three things separately

- **Input:** the original, a relevant excerpt, a recoverable summary, structured data or a native visual/table.
- **Work:** direct action or the smallest method that addresses an observed gap.
- **Output:** the user's required artifact or format, with its required fields, coverage and error states.

A short response still needs the necessary work. Extensive work does not require a long explanation. Deliver every required artifact; a summary is not its replacement.

| Observable need | Next action |
|---|---|
| Missing source fact or changed source/version | Retrieve the relevant authoritative material and check its applicability. |
| Meaning depends on table layout, image or rendered behavior | Inspect that representation with an available domain tool; check the actual artifact. |
| An unresolved format or interpretation distinction | Inspect a relevant example and, if useful, a distinguishing near-miss; do not import its incidental rules. |
| Repeated deterministic computation or transformation | Invoke a suitable executable, or build the smallest permitted one; check its actual outputs against current semantics. |
| Dependent steps obstruct direct execution | Make the smallest useful dependency plan and finish the required result. |
| An important claim or observed error remains unresolved | Use an appropriate source, execution check or independent check to resolve that issue; revise only what it supports. |
| Several plausible methods remain and a distinguishing check is available | Compare bounded alternatives within the task budget; agreement or self-reported confidence is not correctness. |

Honor explicitly requested skills. Otherwise inspect relevant available descriptions and load the smallest complementary skill/reference needed for the next action. Reuse applicable guidance already read. Consult the optional [method catalogue](method-catalogue.md) only when its detail can resolve the gap. Check tool availability and prerequisites; a named technique grants no capability or authority.

## Reduce context without removing requirements

Prefer targeted reads and progressive disclosure to rewriting everything. When compacting, preserve negations, exceptions, units, dates, versions, identifiers, literals, ordering and multiplicity wherever they affect meaning. Keep required output fields, permissions, failures, contradictions and unknowns explicit. Preserve source identity, revision and a usable route to the original.

Recover the original when an exception, conflict, missing detail or stale binding could change the action. Inspect the relevant native representation when text omits meaning. If recovery is unavailable, state the unresolved constraint and continue only unaffected work; do not guess away the requirement. Recheck the resulting artifact against the current contract, including its decisive exception or rejection case where relevant.

Show conclusions and useful evidence, not hidden reasoning. Naming a method or reading a lesson is not applying it: application must reach the tool invocation, artifact or decision. Use REL's existing evidence and handoff process; add no automatic reflection round or new memory system. Count selection and recovery overhead when measured. Shorter context alone establishes neither lower total cost nor better outcomes.

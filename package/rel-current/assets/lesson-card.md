# Optional projection of a verified cycle or change record

Use only when a compact handoff helps a foreseeable next decision. Project an existing record; do not create a competing source of truth or copy private task material into a general shared skill.

**ID/revision and declared state:** candidate / supported within scope / needs recheck / retired

**Observation, counterevidence and source/version:** What actually happened? Where can it be checked? Which correction or later source supersedes it?

**Claim and scope:** Separate the historical outcome from the method it motivates; name what remains unverified.

**Apply when / avoid when:** Observable conditions and a concrete exception; confirm these against the next task rather than relying on similar wording.

**Next action / first verification:** The action this lesson changes and the check that could reverse it.

**Required dependencies / dependent conclusions:** Distinguish indispensable premises from references and alternative independent support.

**Recheck or retirement trigger / cost:** Source, environment, objective or interface changes; maintenance cost and fallback to source search.

For a mechanical manifest, use the exact packet fields in [history consolidation](../references/history-consolidation.md). A complete card or matching digest does not establish truth, durable loading, novelty, a gain or authority to act.

## Branching transfer comparison

Eighteen fresh native model sessions completed: two origin learners and sixteen
later comparisons. Each of six generated migration instances has 4,320 CSV rows
and 1,440 event identities. Civil-time cases change the treatment of ambiguous
times; monetary cases change rounding scope and mode. Complete current rules
were available to every arm. These are substantial controlled transformations,
not independently sampled production documents. Thousands of rows do not create
thousands of independent learning trials.

One origin learner built and retained a reusable executable without an
investigator-provided implementation. The other retained prose lessons only.
The same complete origin bundle was supplied to every retained arm, without
selecting only successful content. Each later session branched from its origin
bundle; it did not inherit the other later session's discoveries. This is not a
long-running compounding sequence.

| Arm | Procedure and available history |
| --- | --- |
| B | Frozen original skill and retained origin bundle |
| C | Frozen compact procedure and the same bundle |
| H | Ordinary work with the same bundle, without REL instructions |
| N | The compact procedure without retained history |

Model, tools and limits were matched: gpt-5.6-sol/medium, native Codex transport,
bounded offline Docker execution, 60 tool actions and 900 seconds per attempt.
The compact procedure was researcher-authored and frozen after origin results.
It jointly changed applicability guidance and process verbosity; this does not
isolate individual wording changes or autonomous procedure invention.

Independent review identified a missing publication of an enforced
phase-dependent tool restriction. The first round was preserved; all second
round arms received the same corrected documentation, with enforcement and
other controls unchanged. The comparison rule was clarified after the first
two B/N cells had launched but before candidate dispatch and before their
outcomes were inspected. These disclosures prevent calling the entire study
fully preregistered or an unchanged-runtime replication.

All 18 final answers were correct. Independent public-action review found actual
policy adaptation in all retained arms. The saved time method was executed by
B/C/H in the first round to regenerate or verify already-produced answers. In
the second round B used it directly for answer production; merely reading it in
other cells was not credited as execution. This establishes a learner-created
method and successful later use, not an advantage caused by the skill.

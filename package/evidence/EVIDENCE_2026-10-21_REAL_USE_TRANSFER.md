# Real-use lesson transfer: qualification only

Two fresh ordinary workers using current REL, with no retained project history,
passed both constructed maintenance tasks. Neither task qualified for the planned
comparison of lesson cards, an equally informed prose handoff and no history.
Ten conditional attempts were skipped. **The added benefit of these lessons was
not tested.** These are two worker attempts, not 132 independent observations.

The tasks covered semantic identity, scope, dependency invalidation, configuration
reuse, replacement, export and reopening; and nested outputs, exact test identities,
interruptions and result reconciliation. All declared public operation names were
represented, which is not exhaustive semantic coverage. The 91-line and 73-line
modules and repeated scenario patterns were too compact to establish the intended
level of substantial real-project difficulty. They were coordinator-constructed,
not independent production failures. No private project code or content was used.

All prepared conditions used the same current REL, model/effort, starter, contracts,
tools and 60-action/900-second limits. The six factual propositions were identical
in the handoff and card packets; only their arrangement differed. Those conditions
were not dispatched because each ordinary endpoint had zero scored errors. No
benefit, harm or tie between history formats can be inferred. The common REL also
prevents a REL-versus-no-REL causal inference.

## Costs and retained failures

The two attempts recorded 494,358 input tokens, including 402,432 cached input,
and 12,828 output tokens: **507,186 total recorded tokens**, or **104,754 uncached
input-plus-output tokens**. Their summed outer elapsed time was 351.70 seconds;
the attempts overlapped. Recorded worker cost per fully passing task was 253,593
total tokens, or 52,377 uncached input-plus-output. No comparative efficiency claim
is supported. Parent research/build/analysis tokens, historical acquisition,
complete human effort and energy remain unknown. There were no extra reflection
model calls or paid provider API calls.

The workspace worker corrected its own invalid semantic-equivalence test, then
adapted a syntax check that had tried writing into a read-only mount. Both failures
remain in the trace despite the final pass. Neither required retained project
history. Before inference, the coordinator fixed aliased fixture data, a removed
CLI path and a runtime manifest mismatch. Two commands attempted after failed
preparation were rejected before dispatch; they were not model trials. Historical
receipts and actual execution bindings are kept separately.

## Disposition

All 20 core files remain unchanged. The existing study-design reference already
requires qualifying errors after ordinary repair. A new mandatory card format,
reflection or history-injection rule is not justified. The package's evidence is
updated without claiming an instructional upgrade.

These two profiles are retired for correctness-benefit comparisons. A useful next
test needs a corroborated error that survives ordinary work in an existing
substantial workflow, and a specific previous observation that could change its
later decision. More parameter variations or a reduced ordinary allowance would
not repair the present task-selection limitation.

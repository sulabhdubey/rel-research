# Connected experience and changed requirements — 24 October 2026

Thirteen fresh native task sessions completed one constructed archive/CSV/SQLite
migration sequence: acquisition plus three later episodes under four policies.
The learner authored scoped lessons, reused test helpers, rejected outdated
note-preservation advice, and revised its method for changing source versions.
All conditions completed every later task: **no correctness advantage was found**.

Common acquisition: 247,972 tokens, counted once in the actual
study total of 3,285,056. Policy totals include their task and
feedback phases. Cached tokens are included subsets. Parent-model work, full
engineering effort, money and energy are unknown; these are recorded worker
costs, not complete project cost. One sequence does not establish a cost effect.

At the first later episode, starting code and O/R/L factual packets matched.
Subsequent stages inherited each policy's own outputs. Every condition retained
code, so N is not state-free. Only L received agent-created lessons and generated
further lessons. The task model, tools, current requirements and allowances were
matched. These were real model/tool executions in a bounded offline coding guest,
not paper simulations or production-system acceptance tests.
The common acquisition used REL; the ordinary control tests later continuation,
not a from-scratch end-to-end strategy without REL. Lesson-authoring overhead is
part of L's policy, so its comparison is not a pure format effect.

The agent's revised advice was checked against actual changes and outputs, not
only the saved lesson text. Controls also succeeded. Fixture/rollback-probe
corrections were preserved before dispatch. A post-dispatch strict output-type
check corrected an insufficient generic comparator and changed no observed score.
All original outcomes remain recorded. All 13 first recorded post-edit public
checks also passed, leaving that metric at a ceiling. Twelve sessions encountered
a wrong documentation path supplied by the host. A prospective exact-path repair
passed checks against all prepared layouts; original attempts remain unchanged.
These host-directed failures are not attributed to memory or independent reasoning.
Other tool actions were counted, not independently judged unnecessary.

This is one constructed integration project, not independent production-project
evidence. The 12 generated evaluation scenarios per episode and worker-authored
stress loops are coverage positions, not independent task samples. The researcher
knows the oracle. Full causal, long-term and portable RSI claims remain open.

All 20 core files are unchanged. Verified study corrections do not justify a new
mandatory instruction. Evidence and the observed workflow example are updated.

## B. Outcome and resource definitions

Task completion means the saved artifact met its declared scored contract. It is not complete specification correctness. First saved decisions, final decisions, tool errors, corrective actions, source validity and lesson invocation are separate observations. No missing field is interpreted as zero.

Total tokens = input + output. Uncached input plus output = total tokens - cached input. Reasoning-output counters are already included in output. Cached input is not added to total again. Token quantities are not currency, hardware energy or total research expenditure.

For S4-S6, query work includes diagnostic probes and final execution. SQLite VM counts are conservative instruction upper bounds; the database work is not a direct measure of remote model inference. CPU and wall timing are host-specific and background work is not fully controlled.

A deployment comparison may charge the full common acquisition to each alternative. That is counterfactual allocation; the actual campaign counts common acquisition once. Costs of parent-model planning, all engineering, user time and physical/remote energy remain unmeasured. No positive energy conclusion is available.

## F. Original brain-AI strand

The broad programme asked how cheap prediction, working state, observation memory and slower updates might improve adaptive systems. Run68, completed 13 October, tested an exposed-input intervention on the Run67 forecasting source. Removing the standardized cap on the current-value feature improved the primary native normalized MSE by 25.834%, across 17,338 scored labels, against the same clipped predecessor. Peak normalized MSE improved by 47.656%.

The primary candidate still had 0.550% worse aggregate MSE than the simple latest-observation predictor, and local/tail harms remained. The intervention changed the fitted and online procedure together; it was not an inference-only experiment. It reused already-exposed source inputs and was not independent confirmation. No claim of biological equivalence, a new architecture, measured energy superiority or general RSI follows.

This is historical context. The programme subsequently tested acquired methods, output-directed computation and source transfer. Those results are registered below; the old uncapped-history proposal is no longer the next action. No brain-AI result is added to agent success denominators or attributed to the current REL wording.
